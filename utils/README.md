# MyKanban Shared Utilities

This directory contains shared utilities, scripts, and configurations used across multiple parts of the monorepo (backend, frontend, e2e).

## Purpose

- Shared constants and configuration schemas
- Cross-project scripts (CI/CD helpers, deployment scripts)
- Shared type definitions or API contracts
- Common development tools and linting configs
