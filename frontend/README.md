# MyKanban Frontend

This directory will contain the MyKanban frontend application.

## Status

🚧 **Coming Soon** — The frontend is currently under development and will be populated in upcoming updates.

## Planned Stack

- React / TypeScript
- Vite build tool
- TailwindCSS for styling

## Getting Started

Once the frontend is set up, you will be able to:

```bash
cd frontend
npm install
npm run dev
```

See the root [README.md](../README.md) for overall monorepo instructions.
